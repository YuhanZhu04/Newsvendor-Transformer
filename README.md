# Newsvendor-Transformer 项目
## Introduction
本项目是基于 Transformer 模型的报童问题（Newsvendor Problem）库存优化预测工具，用于预测服饰类商品的最优订货量，辅助电商平台库存决策。

We have developed a theoretical framework for the Newsvendor-Transformer, proving that it can effectively approximate H\"older continuous conditional quantile functions and generalize well from finite data. The use of median extension in the construction ensures robustness against boundary effects, a critical aspect when applying deep networks to piecewise smooth control maps.
